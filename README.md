# CampusPickleball

Campus Pickleball helps university students find, host, and join pickleball games near campus.

## Getting started

See [DEVELOPMENT.md](DEVELOPMENT.md) for local setup, authentication, database configuration, and checks. Copy `.env.example` to `.env.local` and configure your own credentials; never submit real environment files or credentials.

## Credits and submission

See [CREDITS.md](CREDITS.md) for the starter template, open-source package citations, services, and venue data sources used by this project. Direct dependencies are declared in [package.json](package.json), with the dependency tree and resolved versions recorded in [package-lock.json](package-lock.json).

For the HackPSU submission, attach the project source or provide an accessible source repository link in Devpost. Including this README alone does not attach the code to the submission. Include `CREDITS.md`, `package.json`, and `package-lock.json` with the source; exclude `.env.local`, credentials, `node_modules`, and generated build output.
